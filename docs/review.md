## 0. 무엇에 답하나

**"내가 산 근거는 맞았나."** 두 층으로 답한다.

| 층 | 질문 | 단위 |
|---|---|---|
| 개별 | 이 매수는 그때 저장된 근거(점수·신호·팩터) 대비 어떻게 끝났나 | 매수 결정 하나 |
| 통계 | 어떤 신호·기간이 실제로 맞았나 | 신호 종류별 · 기간별 · 전체 |

목적은 규칙을 **바꾸는 근거**를 모으는 것이다. 다만 표본이 적을 때는 단정하지
않는다(`CLAUDE.md` Step 15 완료 기준). 열 건으로 "밸류가 통한다" 고 말하지 않는다.

## 1. 복기의 단위 — 매수 결정

`trade_lots` 는 FIFO 로 매도 한 건이 매수 여러 건과 짝지어진 행이다. 그대로 세면
관찰이 부풀어 통계가 왜곡된다(매수 셋을 한 번에 팔면 3건으로 센다).

그래서 **매수 거래(`trades.side='buy'`) 하나를 관찰 하나**로 본다. 그 매수에 짝지어진
lot 들을 합친다.

```
원가      = Σ lot.cost                      (종목 통화, 매수 수수료 포함)
실수령    = Σ lot.proceeds                  (매도 수수료·세금 제외)
수익률    = 실수령 / 원가 − 1               (비용 반영, 종목 통화 기준)
보유일    = Σ(lot.holding_days × lot.quantity) / Σ lot.quantity   (수량 가중)
원화 손익 = Σ realized_pnl_krw, 주가 손익·환차손익도 각각 합
```

화면은 해외 매수의 수익률에 "(USD 주가)" 를 붙이고 원화 손익을 **주가·환으로 나눠** 적는다 — 수익률(주가)과 원화 손익(환 포함)의 부호가 반대일 수 있어서다 (docs/infra.md 25.241).

- 일부만 판 매수는 **판 만큼만** 복기하고 `partial` 로 표시한다. 남은 수량은 아직
  결과가 없다
- 매수 근거는 그 매수 행에 얼려 둔 스냅샷(`docs/portfolio.md` 1장)이다. 스냅샷이 없는
  매수(점수가 없던 종목, 배치 전 입력)는 개별 표에 "저장된 근거 없음" 으로 남고,
  **신호별 통계에서는 뺀다.** 근거 없는 건을 근거별 통계에 넣을 수 없다

## 2. 결과 판정

매수 시 입력한 투자 기간의 목표·손절(설정 `horizon_targets`)과 견준다.

| 판정 | 조건 |
|---|---|
| `target` | 수익률 ≥ 목표 |
| `gain` | 0 < 수익률 < 목표 |
| `flat` | 수익률 = 0 |
| `loss` | 손절 < 수익률 < 0 |
| `stop` | 수익률 ≤ 손절 (퍼센트로 바꿔 소수 여섯째 자리에서 반올림한 뒤 견준다 — 매도 플래그와 같은 잣대, docs/infra.md 25.243) |

- 목표·손절은 **복기 시점의 설정**이다. 매수 당시와 다를 수 있다. 그 사실을 화면에
  적는다 `[확인필요: 매수 시점의 목표·손절을 스냅샷에 함께 얼릴지]`
- 기간이 없는 매수(`horizon` NULL)는 목표·손절 판정을 하지 않고 수익률만 본다

## 3. 통계

집단마다 다음을 낸다. 전부 **1장의 매수 결정**이 관찰이다.

| 항목 | 식 |
|---|---|
| `n` | 관찰 수 |
| `win_rate` | 수익률 > 0 인 비율 |
| `avg_return_pct` | 수익률 **원가 가중** 평균. 큰 매수가 더 많이 반영된다. 가중치는 **매수일 환율로 원화 환산한 원가**다 — 국내·미국이 섞인 집단에서 원과 달러를 그대로 더하지 않는다 (docs/infra.md 25.289) |
| `median_return_pct` | 중앙값. 한 건의 대박·쪽박에 덜 흔들린다 |
| `avg_holding_days` | 보유일 평균 |
| `target_rate` `stop_rate` | 판정이 `target` / `stop` 인 비율 (기간이 있는 것만) |
| `total_pnl_krw` | 원화 손익 합 |

집단은 셋이다.

| 집단 | 키 | 포함 |
|---|---|---|
| 전체 | `all` | 모든 복기 행 |
| 기간별 | `horizon:short` … | 기간이 있는 행 |
| 신호별 | `signal:실적 모멘텀` … / `signal:없음` | 스냅샷이 있는 행. 신호 없이 산 것은 `signal:없음` 으로 따로 센다 — "신호 없이 산 매매가 신호 있는 것보다 나은가" 도 답이다 |

### 표본이 적으면 단정하지 않는다

```
MIN_SAMPLE = 10        출발값. 근거 없음 [확인필요: 몇 건부터 믿을지]
```

`n < MIN_SAMPLE` 이면 `sample_ok = false` 로 두고 화면은 그 집단의 숫자를 **회색으로,
"표본 N건 — 단정하지 않는다" 와 함께** 보여준다. 숫자를 숨기지는 않는다. 숨기면
"왜 안 나오지" 가 되고, 보여주되 경고하면 "아직 모른다" 가 된다.

**일부만 판 매수는 통계(n·승률·평균·중앙값·보유일·목표/손절 비율)에서 뺀다** (2026-09-29, calc_version 2, docs/infra.md 25.694).
판 몫만 보면 이익 난 몫을 먼저 파는 습관이 승률을 부풀린다. 실현손익 합계와 `members` 에는 넣고, 뺀 건수를 집단 이름 옆에
"(일부 매도 N건 제외)" 로 적는다. 목표·손절 비율은 **분모(기간이 있는 행)가 집단 n 과 같거나 MIN_SAMPLE 이상일 때만** 낸다 —
표본 충분 집단의 비율이 3건으로 나는 일을 막는다.

## 4. 근거 문장 — 저장된 수치만

```
중기 · 실적 모멘텀 · 매수 시 점수 78 → +12.3% (41일). 목표 +25% 미달, 손절 유지
장기 · 저장된 근거 없음 → −9.8% (120일). 손절 −25% 유지
```

값이 없는 부분은 문장에서 빠진다. "양호" 같은 말로 채우지 않는다(`signals.py` 와
같은 규칙). 화면은 문장 아래에 스냅샷 원본(기준일·종합 점수·팩터·센티먼트)과 결과
원본(lot 합계)을 표로 펼쳐 **확인할 수 있게** 한다(`CLAUDE.md` 절대 규칙).
