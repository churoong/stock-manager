# 텔레그램 질의응답

- 작성 2026-10-07. 사용자 지시("다 진행해", 차별점 8번). 기록 docs/infra.md 25.1004
- 코드: `web/lib/telegramQa.ts`(질문 해석·답 만들기), `web/app/api/telegram/webhook/route.ts`(텔레그램이 부르는 경로),
  `web/app/api/telegram/webhook-setup/route.ts`(켜기·끄기), `web/components/TelegramQaSetup.tsx`(설정 화면 단추)

## 1. 무엇을 하나

봇에게 말을 걸면 앱을 열지 않고도 DB 에 있는 값을 받는다. 아침 리포트와 장중 알림은 우리가 보내는 것이고, 이것은 **사용자가 묻는 것**이다.

| 보내는 말 | 답 |
|---|---|
| 종목 이름·티커 (`삼성전자`, `005930`, `AAPL`, `/종목 AAPL`) | 마지막 종가와 날짜, 종합 점수·시장 순위·다섯 팩터(기준일), 가장 최근 매수 신호(기간·매수 구간·목표·손절), 보유 수량·평균단가·평가손익률, 오늘 걸린 매도 플래그 |
| `/보유` | 보유 종목 손익률 순 20개와 비중 |
| `/알림` | 가장 최근 장중 알림 날의 알림 20건 |
| `/도움`, `/start`, 그 밖의 명령 | 안내 |

- **유료 LLM 을 쓰지 않는다**(CLAUDE.md). 문장은 템플릿이고 숫자는 DB 행 그대로다. 없는 숫자를 만들지 않는다 — 점수가 없으면 "아직 없음", 계산하지 못했으면 그 사유(`skip_reason`)를 적는다
- 이름은 정확히 같은 것을 먼저, 그다음 앞부분이 같은 것을 찾는다(5개까지). 여럿이 맞고 정확히 같은 것이 하나가 아니면 이름 목록을 주고 다시 고르게 한다
- 30자를 넘는 말은 종목 이름이 아니라고 보고 안내를 준다
- **읽기만 한다.** 매매 입력·설정 변경·발송 명령은 두지 않는다. 근거표는 앱의 종목 화면에서 펼쳐 보라고 끝에 적는다(근거표는 화면에 있다 — 절대 규칙)

## 2. 누가 부를 수 있나 — 두 겹

웹훅은 텔레그램이 부르는 경로라 로그인 쿠키가 없다. `web/proxy.ts` 가 **정확히 이 경로 하나만**(`/api/telegram/webhook`) 로그인 없이 연다. 켜기·끄기 경로(`webhook-setup`)와 그 아래 다른 경로는 그대로 로그인 뒤다. 경로는 스스로 두 겹을 확인한다.

1. 머리글 `X-Telegram-Bot-Api-Secret-Token` 이 Vercel 환경변수 `TELEGRAM_WEBHOOK_SECRET` 와 같아야 한다. 웹훅을 걸 때 텔레그램에 준 값이라 텔레그램만 안다. 다르면 401. 환경변수가 없으면 404(질의응답이 꺼진 것)
2. 말이 **본인 대화방**(`TELEGRAM_CHAT_ID`)에서 와야 한다. 다른 대화방(봇 이름을 아는 누구든)의 말에는 답하지 않는다 — 한국거래소·KIS 데이터의 제3자 제공 금지(CLAUDE.md)

경로는 **언제나 200 으로 끝낸다**(인증 실패 제외). 아니면 텔레그램이 같은 말을 계속 다시 보낸다. DB 를 못 읽으면 "답을 만들지 못했습니다" 를 보내고, 답장 발송이 실패해도 200 이다.

## 3. 켜기

1. Vercel 환경변수에 `TELEGRAM_WEBHOOK_SECRET` 를 넣는다 — 16자 이상, 영문·숫자·`_`·`-`(텔레그램 `secret_token` 허용 문자 `[확인필요: 텔레그램 Bot API 명세의 길이 상한 256]`). 넣은 뒤 다시 배포해야 경로가 읽는다
2. 설정 화면 "텔레그램으로 물어보기" 의 **켜기** 를 누른다. 경로가 텔레그램 `setWebhook` 에 지금 접속한 출처의 `/api/telegram/webhook` 과 비밀값을 넘긴다(말만 받기, 밀린 말은 버림). 웹앱 주소는 저장소·문서에 적지 않는다(공개 저장소 규칙)
3. 끄기는 `deleteWebhook`

웹훅을 걸면 텔레그램 `getUpdates` 를 쓸 수 없다. 설정 화면의 텔레그램 테스트가 대화방 번호가 비었을 때 보여 주는 "최근 대화방 번호 후보" 는 그동안 비어 있다(발송에는 영향이 없다).

## 4. 비용과 한도

- Vercel 함수 호출이 말 한 번에 한 번 늘고, DB 읽기가 종목 질문 한 번에 다섯 질의(각 1~수 행), `/보유`·`/알림` 은 한 질의(20행 상한)다. 사람이 손으로 보내는 말이라 하루 수십 번 수준이다 — 무료 한도(docs/infra.md) 안
- 텔레그램 Bot API 는 무료다

## 5. 하지 않은 것

- 자연어 질문("요즘 반도체 어때?")은 받지 않는다 — 유료 LLM 금지. 명령과 종목 이름만
- 같은 말이 두 번 오면(텔레그램 재전송) 두 번 답한다 — 읽기라 해가 없어 막지 않았다
- 그룹 대화방은 생각하지 않았다. 본인 대화방 번호 하나만 받는다
