# API 키 발급 안내

- 여기 나오는 것은 **전부 무료**입니다. 카드 등록을 요구하는 단계가 나오면 멈추고 알려주세요.
- 발급받은 키는 **`.env` 파일에만** 넣습니다. 코드나 문서에 붙여넣지 않습니다.
- 키를 채팅창에 붙여넣지 마세요. `.env`에 직접 입력하시면 됩니다.
- 한도와 조건이 확인되지 않은 항목은 `[확인필요]`로 두었습니다. `docs/data-sources.md`에서 확정합니다.

발급 순서는 아래 우선순위대로 하시면 됩니다. **1번과 2번만 있어도 Step 1은 돌아갑니다.**

---

## 1. 텔레그램 봇 (필수, 가장 먼저)

Step 1의 검증 대상이라 이것부터 필요합니다. 5분이면 끝납니다.

1. 텔레그램 앱에서 `@BotFather`를 검색해 대화를 시작합니다.
2. `/newbot` 입력
3. 봇 이름을 묻습니다. 아무 이름이나 됩니다. 예: `내 주식 알림`
4. 봇 아이디를 묻습니다. **반드시 `bot`으로 끝나야** 합니다. 예: `churoong_stock_bot`
5. 토큰이 나옵니다. `숫자:영문자` 형태의 긴 문자열입니다. 이게 `TELEGRAM_BOT_TOKEN`입니다.
6. 방금 만든 봇을 검색해 대화방을 열고 아무 메시지나 한 번 보냅니다. **이 단계를 건너뛰면 봇이 나에게 메시지를 못 보냅니다.**
7. `chat_id`는 Step 1에서 만들 스크립트가 자동으로 찾아 설정에 저장합니다. 직접 찾고 싶으면 브라우저에서 아래 주소를 열면 `"chat":{"id":숫자}`가 보입니다.

```
https://api.telegram.org/bot<여기에_토큰>/getUpdates
```

`.env`에 넣을 것:

```
TELEGRAM_BOT_TOKEN=발급받은_토큰
```

> 토큰이 유출되면 누구나 내 봇으로 메시지를 보낼 수 있습니다. 유출이 의심되면 BotFather에서 `/revoke`로 재발급하세요.

## 2. DART OpenAPI (필수, 국내 재무·공시)

금융감독원 전자공시 시스템입니다. 국내 종목 재무제표와 공시의 유일한 공식 무료 소스입니다.

1. https://opendart.fss.or.kr 접속
2. 상단 **인증키 신청/관리** → **인증키 신청**
3. 이름, 이메일, 사용 목적을 입력합니다. 목적은 "개인 투자 참고용 데이터 분석" 정도로 쓰면 됩니다.
4. 이메일로 인증키가 옵니다. 40자 길이의 영숫자 문자열입니다.

```
DART_API_KEY=발급받은_인증키
```

- 무료 한도: `[확인필요]`
- 개인 비상업 이용 가능 여부와 재배포 조건: `[확인필요]`

## 3. KRX 정보데이터시스템 Open API (종목 마스터·지수, Step 3)

국내 종목 목록과 업종 지수의 공식 무료 원천입니다.

1. https://openapi.krx.co.kr 접속 후 회원가입
2. 약관 동의 후 **인증키 신청**
3. 인증키를 받은 뒤, **쓰려는 API마다 "이용신청"을 따로** 해야 합니다. 이 단계를 빠뜨리면 키가 있어도 호출이 막힙니다.

```
KRX_API_KEY=발급받은_인증키
```

- 무료 한도: **키당 하루 10,000회**
- 인증키 유효기간은 1년이고, 12개월 동안 쓰지 않으면 사전 공지 없이 삭제됩니다.
- 이용 조건: 약관에 **비상업 목적으로만 이용 가능**, **제3자 제공 금지**가 명시돼 있습니다. 이 앱은 내 PC에서 혼자 쓰므로 부합합니다. 화면이나 데이터를 외부에 공개하면 위반입니다.

## 4. 네이버 검색 API — **지금은 신청하지 마세요**

국내 뉴스 수집에 쓰려던 것인데, 조사 결과 **레거시 검색 API가 종료 절차에 들어간 것으로 보입니다.**

2차 자료 두 곳이 교차로 전하는 내용은 이렇습니다. 2026년 7월 말에 신규 애플리케이션 등록이 중단됐고, 기존 키는 2027년 6월 말까지만 쓸 수 있으며, 네이버 클라우드 쪽으로 이관됩니다. 사실이라면 **오늘 기준으로 신규 등록 자체가 안 될 수 있습니다.** 이관 대상 서비스는 클라우드 계정이 필요해 결제수단 등록을 요구할 가능성도 있습니다. 무료 조건과 충돌합니다.

또한 검색 API 특약이 캐싱과 저장을 제한한다는 보도가 있어, 뉴스 제목과 점수를 저장하는 이 앱의 구조와 맞지 않을 수 있습니다.

**시간이 되실 때 브라우저로 https://developers.naver.com 에 직접 접속해 신규 등록이 되는지만 확인해 주세요.** 도구로는 사이트가 차단돼 확인이 안 됩니다. 결과에 따라 Step 7에서 국내 뉴스 소스를 언론사 공식 RSS로 바꿉니다.

## 5. 한국투자증권 KIS Developers — **발급하지 마세요**

2026-09-16에 선택 항목으로 내렸습니다. **지금은 필요 없습니다.**

이 API가 유일하게 주는 것은 장중 실시간 시세와 공식 휴장일 조회 둘뿐입니다. 나머지 국내 데이터는 한국거래소와 DART로 전부 덮입니다. 반면 실계좌 개설과 HTS ID 등록이 필요하고, 무엇보다 **클라우드에서 호출되는지가 확인되지 않았습니다.** 배치가 GitHub에서 도는데 그 주소는 실행마다 바뀌는 해외 대역입니다. 호출 IP 등록이 필수라면 계좌를 만들어도 쓸 수 없습니다.

타협한 것은 장중 알림이 십몇 분 늦어진다는 점 하나입니다. 자동 매매가 없고 알림이 판단 참고용이라 견딜 만하다고 판단했습니다.

나중에 장중 정확도가 아쉬워지면 그때 붙입니다. 어댑터 구조라 파일 하나를 추가하면 됩니다. 조사한 조건은 `docs/data-sources.md` 3번에 남겨 뒀습니다.

## 6. FRED (미국 무위험수익률) — **아직 안 붙였습니다**

> **2026-09-23 정정.** 아래는 발급 절차 그대로 남겨 두지만, **지금 이 키는 아무 데서도
> 읽히지 않습니다** (docs/infra.md 25.160). Step 5 를 마칠 때 무위험수익률을
> **설정 화면 수동 입력**으로 갔고, FRED 를 받아 오는 코드는 끝내 안 만들었습니다.
> 키를 넣어도 달라지는 것이 없습니다. 무위험수익률은 **설정 → 무위험수익률**에
> 직접 넣으세요. 안 넣으면 샤프·소르티노가 비고, 설정 화면이 빠진 값으로 알려 줍니다.

미국 3개월 국채 금리를 받습니다. 샤프지수 계산에 필요합니다.

1. https://fredaccount.stlouisfed.org 접속 후 계정 생성
2. **API Keys** → **Request API Key**
3. 사용 목적을 간단히 적으면 32자 키가 발급됩니다.

```
FRED_API_KEY=발급받은_키
```

- 무료 한도: `[확인필요]`. 공식 문서에 숫자가 없습니다. 분당 120회라는 수치가 널리 쓰이지만 공식이 아닙니다.
- 쓸 시리즈는 확정했습니다. 일별은 `DTB3`, 월별은 `TB3MS`입니다.
- **고지 의무가 있습니다.** 붙이는 날 앱 화면에 다음 문구를 표기해야 합니다. 문구는 `batch/config.FRED_NOTICE` 와 푸터에 **미리 넣어 두었습니다** — 나중에 넣으려면 그때 아무도 기억하지 못하기 때문입니다.

  > This product uses the FRED® API but is not endorsed or certified by the Federal Reserve Bank of St. Louis.

## 7. 한국은행 ECOS (국내 무위험수익률) — 선택, **아직 안 붙였습니다**

> 무료 한도가 확인되지 않아 **사용 보류**입니다(CLAUDE.md 비용 규칙). 6번과 마찬가지로
> 받아 오는 코드가 없습니다. 국내 무위험수익률도 설정 화면에 직접 넣으세요.

CD 91일물 또는 국고채 3년물 금리를 받습니다. **건너뛰셔도 됩니다.**

1. https://ecos.bok.or.kr 접속
2. **오픈API** → **인증키 신청**
3. 회원가입하면 인증키가 자동 부여됩니다.

```
ECOS_API_KEY=발급받은_키
```

- 무료 한도: `[확인필요]`. 2차 자료가 하루 1,000회, 10,000회, 20,000건으로 **셋으로 갈립니다.** 공식 문서를 열지 못해 확정하지 못했습니다. 키를 받으시면 마이페이지 이용현황에서 실제 숫자를 볼 수 있습니다.
- 출처 표시 의무가 있습니다. 한국은행이 출처임을 표기해야 합니다.
- CD 91일물과 국고채 3년의 통계 항목코드도 `[확인필요]`입니다. 추측값을 코드에 넣지 않고, 키 발급 후 항목 목록을 조회해 실측하겠습니다.

> **6번과 7번은 건너뛰세요.** 설정 화면의 수동 입력이 **지금 있는 유일한 길**입니다(2026-09-23 확인). 금리는 자주 바뀌지 않아 수동 입력으로 충분합니다.

## 발급 후 할 일

1. 프로젝트 루트에 `.env` 파일을 만듭니다. Step 1에서 `.env.example`을 드리니 복사해서 값만 채우시면 됩니다.
2. `.env`는 `.gitignore`에 들어 있어 커밋되지 않습니다. 확인했습니다.
3. 설정 화면의 **텔레그램 테스트 발송** 버튼으로 1번이 제대로 됐는지 먼저 확인합니다.

## 남은 계정 준비 (Step 0에서)

API 키가 아니라 실행 환경입니다. 전부 무료이고 카드가 필요 없습니다.

| 서비스 | 용도 | 비고 |
|---|---|---|

이 계정들에서 나오는 값은 `.env.example`의 2~5번 묶음에 해당합니다. Step 0에서 함께 채웁니다.
