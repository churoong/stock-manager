> 가상모의투자와 KIS모의투자가 이 시스템의 핵심역할을 해야해. 지금까지 만들었던 종목선정, 분석 등은 해당 매매를 위한 전략을 짜기 위해서 만든거고,
> 가상, KIS 모의투자가 어느정도 데이터가 쌓여서 매매전략을 수정 보완하여 확신히 생기면 그땐 이 전략들을 가지고 실전투자에 활용할거야."

## 3. 스택

- 2026-09-16 변경: PC가 꺼져 있어도 폰으로 전부 확인해야 하므로 배치와 화면을 모두 무료 클라우드로 옮겼다. 변경 이유와 대조표는 docs/design.md 1.3·1.6절.
- Alembic 을 쓰지 않는 까닭: Alembic 은 SQLAlchemy 방언을 요구하는데 Turso 용 파이썬 드라이버가 낡아 동작하지 않는다(docs/infra.md 2번).
- 2026-09-20 정정: SQLAlchemy 모델을 만들겠다고 적어 두었지만 끝내 만들지 않았고, SQLAlchemy 는 어디서도 import 하지 않는다.
  그때까지 CLAUDE.md 는 "스키마 변경은 Alembic으로 관리", "단일 정의처는 SQLAlchemy 모델", "마이그레이션: alembic upgrade head" 라고
  사실과 다르게 적고 있었다. `tests/test_requirements.py` 가 그 문구가 돌아오지 않게 잠근다.
