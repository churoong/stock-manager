# 증권사 적중률 성적표 (2026-10-07, docs/infra.md 25.995)

> 사용자 지시(2026-10-07 "다 진행해") — 차별점 1번. 증권사 의견·목표가는 어디서나 보이지만 **그 증권사가 지난번에 얼마나 맞혔나**
> 는 잘 보이지 않는다 `[확인필요: 다른 앱의 같은 기능]`. 우리는 KIS 투자의견 1년치(`kr_opinions`, 25.988)와 우리 시세로 잰다.

## 1. 무엇을 재나 (`batch/services/broker_stats.py`)

증권사마다, 목표가가 있는 의견 하나하나에 대해:

- **기준가** = 발표일 **다음 거래일** 종가 (당일 종가에는 장 뒤 발표의 반응이 섞일 수 있다 `[확인필요: 발표 시각]`)
- **제시 상승여력** = 목표가 ÷ 기준가 − 1. 증권사 평균이 크면 낙관 편향이다
- **60거래일 초과수익** = 기준가에서 60거래일 뒤 종가 수익 − 같은 기간 지수(코스피·코스닥, 종목 시장대로) 수익.
  **상향 목표가**(상승여력 > 0)만 센다. "맞힘" = 초과수익 > 0 의 비율
- **목표가 터치** = 기준일부터 120거래일 안에 고가가 목표가 이상. 상향 목표가만, 120거래일이 다 지났거나 이미 닿은 것만 센다
  (증권사 목표가는 대개 12개월이지만 우리 이력이 1년이라 반년으로 본다 `[확인필요]`)
- **기간 안 분할·병합**(수정계수 adj_close ÷ close 가 2% 넘게 바뀜)이면 그 의견은 뺀다 — 목표가와 주가의 단위가 달라진다

## 2. 보이는 곳

- 종목 화면 "증권사 의견 · 그 증권사의 지난 성적" — 최근 의견 15건마다 그 증권사의 한 줄:
  `60거래일 초과수익 평균 +1.2%p · 맞힘 54% (83건) · 목표가 터치 31% (40건) · 제시 상승여력 평균 +38%`
- 60거래일이 지난 상향 목표가 의견이 **20건 미만**이면 "표본 부족" 으로만 적는다(`MIN_N`)

## 3. 언제

국내 수급 수집(`kis-flows.yml`) 끝에 `batch/jobs/broker_stats.py` — **금요일**이거나 표가 비었을 때만 다시 계산한다(시세 약 25만 행을 읽는다).
표 `broker_stats` 를 통째로 바꾼다(계산 결과라 언제든 다시 만들 수 있다).

## 4. 하지 않는 것

- 성적으로 우리 점수·신호를 바꾸지 않는다 — 표시일 뿐이다. 쓰려면 docs/factors.md 에 식을 먼저 적고 백테스트한다
- 하향 의견(목표가 < 기준가)은 맞힘·터치에 넣지 않는다 — 표본이 너무 적다

## 5. 읽을 때 주의할 것

- **표본이 1년치다.** KIS 는 종목마다 1년에 100행까지 준다(25.988). 60거래일 초과수익은 의견 뒤 석 달이 지나야 익고, 목표가 터치는
  반년이 지나야 정해진다. 그래서 처음 몇 달은 "표본 부족" 이 많다. 매일 쌓으므로 시간이 갈수록 익은 의견이 늘어난다
- **증권사가 덮는 종목이 다르다.** 대형주만 덮는 증권사와 중소형주를 많이 덮는 증권사는 같은 잣대로 비교하기 어렵다 —
  초과수익은 지수를 빼서 시장 전체의 움직임은 덜어 내지만, 업종·크기의 차이는 남는다 `[확인필요: 업종 중립 비교]`
- **같은 날 여러 증권사가 같은 종목을 올리면** 서로 독립이 아니다. 한 사건(실적 발표)에 몰린 의견들이 함께 맞거나 함께 틀린다.
  건수가 많아 보여도 실제 독립 표본은 더 적다
- **목표가 터치는 하루 고가 기준**이다. 장중 한 번 닿았다 내려와도 "닿음" 으로 센다 — 실제로 그 가격에 팔 수 있었는지와 다르다
- **의견 등급 문구는 증권사마다 다르다**(BUY·매수·Outperform·비중확대). 그래서 등급이 아니라 목표가의 방향(상승여력의 부호)으로
  상향·하향을 가른다
- **우리 점수와 섞지 않는다.** 이 표는 "그 증권사 말을 얼마나 믿을까" 를 사람이 판단하도록 돕는 참고다

## 6. 손으로 따라가 보기 (테스트 `tests/test_broker_stats_995.py` 와 같은 숫자)

| 단계 | 값 |
|---|---|
| 발표일 | 1월 1일, 목표가 150원 |
| 기준가 | 다음 거래일(1월 2일) 종가 100원 → 제시 상승여력 +50% |
| 60거래일 뒤 종가 | 120원 → 종목 수익 +20% |
| 같은 기간 지수 | 1,000 → 1,050 → +5% |
| 60거래일 초과수익 | +20% − 5% = **+15%p** → 맞힘 |
| 120거래일 안 고가 최대 | 120원 < 150원, 120거래일이 다 지났다 → **터치 못함** |

증권사의 줄은 이런 의견들을 모은 평균·비율이다. 분할·병합이 낀 의견은 처음부터 빠진다(빠진 수는 `skipped_action` 에 남는다).
